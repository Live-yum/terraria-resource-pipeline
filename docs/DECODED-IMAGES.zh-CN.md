# 已提取 PNG 的私有导入检查

如果以前的桌面工具已经导出了 PNG，可以先检查这些已有图片，不必为了图片检查重复取得 XNB。此功能是独立的命令行预检，尚未接入网页双来源上传入口或真实游戏发布流程。

```sh
PYTHONPATH=src python -m resource_pipeline.decoded_images /private/export-images.zip --version-hint 1.4.5.8 > /private/image-inventory.json
```

输入只允许 PNG，目录层级保持不变。ZIP 路径、链接、条目数、单文件/总体大小和压缩比例使用既有安全限制；图片限制为单帧 PNG、单张 1600 万像素、总计 2.56 亿像素。默认 ZIP 上限为 512 MiB、展开 2 GiB、50,000 条目；16,000 张原创合成图片的整包检查已通过。这些条目/字节上限容纳约 15,000 张、52 MB 的已有导出，但整包是否满足总像素限制仍须实际解码判断，不能由压缩体积保证。工具不联网，不执行包内代码，不更改输入，不复制到 CDN，也不输出公开图片包。输出清单包含原 ZIP SHA-256、每张图片 SHA-256、尺寸以及包含尺寸的 RGBA 像素哈希；同像素但不同 PNG 附加元数据可识别为重复。

报告始终标记 `versionVerified=false`、`extractionComplete=false` 和 `publishable=false`。文件夹名、版本提示及已提取图片不能证明原客户端版本、XNB 到 PNG 的转换链、图片覆盖率或发布权利。

已有图片可进一步进入既有无损 PNG 规范化/去重函数，但仍需可信源绑定与语义适配器才能形成可发布资源目录。图片命名不能直接替代以下证据：

- 物品/人物/方块/墙的完整 ID 域与资源别名
- 人物、NPC 和图集的有效帧、裁图与绘制关系
- 物品属性、动态说明及中英本地化
- 地图多选项颜色、涂料/涂层、照明和像素 RGB 候选规则
- 原客户端版本、服务端同版本配对及资源授权

## TConvert 的可参考范围

TConvert 的典型工作方式是读取已安装客户端的 `Content` 中的 XNB，提取 PNG；它不是客户端下载器。原桌面版本基于 Windows/.NET Framework，命令行构建也不自动意味着 Linux 支持。部署前应审核锁定源码、依赖与许可证，并使用只读输入、无网络和资源限制执行；不能将历史桌面工具直接作为不受限的上传处理器。

本模块为独立实现，没有复制第三方转换器源码。公开测试仅使用自行生成的 PNG。实际版本图片与私有审计报告应存放于私有工作目录，不能提交到公开仓库。
